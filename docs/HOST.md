# 主持人小抄

開啟 `host.html`，用指定正式帳號登入。建立房間，分享觀眾網址及六位房間碼。房間最多 20 人；入座人數是已加入名單，不是目前在線偵測。

1. 選題，按「開始這題」，預設 45 秒。
2. 觀眾的「我的答案」與「預測最多人選」一起提交，截止前可改。猜中得 1 分；並列任一最高票都算；零票不計分。
3. 看「本輪 X 人已提交」決定是否延長 15 秒或提前截止，不必等齊。已到期不能延長，避免偷偷重開作答。
4. 到期自動鎖作答；按「揭曉答案」發布結果。重複揭曉不會多加分。
5. 留空間分享；觀眾在揭曉後投稿，先只有本人與你能看。按「選到直播展示」才公開，按「撤下展示故事」移除公開副本。下一題會停止展示上一題故事。
6. 選下一題並開始。你可以鎖定加入、關閉聊天、刪除最近訊息、禁言或移除名單中的身分。禁言亦禁止故事投稿，但不禁止作答；移除阻止作答／聊天／重新加入。
7. 結束後可留著結果，或按清理永久刪除這場資料。

重整主持頁會恢復登入及房間。主持人斷線時，Firebase 仍以伺服器時間擋下過期答案；重連後恢復主持，若已到期會切換截止。若顯示離線或送出等待中，先等連線恢復，不要把尚未確認的操作當成功。不要兩個主持分頁同時按下一題；每輪結算可重試，但操作者仍應只有一位。

## 島民默契操作

每次揭曉後會同步更新島民分布。主持頁「島民默契」選一位玩家，可查看他與其他人的共同題數、相同題數、百分比及是否達門檻，不能人工改分。共同至少 2 題且相同率至少 70% 才有靠攏資格；漏答不扣分，預測答案不參與。群聚還要求群內每一對合格，所以達門檻的兩人不一定都在同群。

玩家只看到大致位置，可能推測彼此相似，讀不到精確數值。這不是人格或心理測驗。公開「猜大家排行榜」仍然只計預測命中的 1 分。移除玩家即撤下角色；新 UID 不繼承舊座位默契。

舊房間首次用新版主持頁時自動從已揭曉紀錄重建。若沒有歷史答案就無法補算該題；未揭曉答案不會納入。發布請在活動結束後操作，先上傳規則，再更新网站並重整主持頁。

## OBS 展示設定

新增 Browser Source，網址填正式 `display.html`，寬 1920、高 1080。它只展示公開題目、入座人数、結果、排行榜及一則已選故事，不會自動輪播聊天室。開始新場前確認畫面顯示正確房間碼。電腦瀏覽器預覽不能代表真實 OBS 已驗收，試播時要檢查字級、來源刷新、縮放和直播安全區。

## 15 分鐘試播

| 時間 | 動作與檢查 |
|---|---|
| 0–2 分 | 主持登入開房；2–3 位朋友加入，確認暱稱及房間碼。展示頁不登入。 |
| 2–5 分 | 第一題暖場。示範分開選自己／預測、修改再提交；其中一人重整，確認身分和答案恢復。 |
| 5–7 分 | 提前截止，確認不能改；揭曉再按一次，分數不增加。請觀眾說理由，不評定人格。 |
| 7–10 分 | 投稿兩則故事；只選一則到直播，再撤下。確認另一則未出現在 OBS。送一則含 `<b>` 的訊息，應顯示文字而不是 HTML。 |
| 10–12 分 | 第二題延長；關聊天、禁言測試身分、解除禁言；移除測試身分並確認原身分不能回來。 |
| 12–14 分 | 手機切斷網路再重連，觀察離線提示；逾時後確認不能補送。主持刷新，再開一題零人作答並揭曉，確認 0 分。 |
| 14–15 分 | 結束房間；查看 Firebase Usage；確認是否需要留結果，再清理。 |

匿名身分不能防止真人換瀏覽器重入；遇到騷擾可以先鎖定加入、關聊天再處理。不整合 Twitch 聊天室，請口頭提醒不要在 Twitch 提前暴雷。

## 新版主持介面位置

房間碼與分享網址在「主持小桌」左側，手機則在標題下方。「本輪控制」顯示提交人數、下一步提示、選題及截止／揭曉按鈕。「結束房間」「清理資料」「登出」移到可展開的「房間管理與登出」。按鈕作用及清理確認流程不變。

## 邀請連結與 QR Code

在主持頁的房間碼下方，按「複製邀請連結」即可分享帶有房間碼的網址；玩家開啟後只需輸入暱稱。按「顯示入場 QR Code」可讓手機掃描。QR 在瀏覽器產生，不會把連結交給第三方圖片服務。

房間鎖定時暫停複製及 QR 展示；結束後隱藏邀請工具。本機或示範網址會提醒無法用作跨裝置正式邀請。若瀏覽器拒絕剪貼簿存取，會選取連結供手動複製。正式邀請請在 GitHub Pages 主持頁操作。
