# 輪流猜主角題庫擴充

目標：1,000 題，10 個分類各 100 題。保留 q1–q30 識別碼，重寫內容；其餘題號按分類預留 97 題。

題目規範：
- 限定單一情境、時間點或有限資源，優先問第一步、只能選一項或最後決定。
- 四項回答同一問題，避免性格、行動、原因混雜或上下位重疊。
- 不按道德高低區分答案，不推斷人格、疾病或關係好壞。
- 趣味來自具體習慣與預期落差，吐槽行為而非身份；允許不分享細節。
- 每題附一個揭曉追問，鼓勵說真實例子，不在作答前暗示答案。
- 不以替換物件名稱或排列組合湊數，逐題寫情境與選項。
- 題幹維持中性第二人稱，兩個作答區各自標示對象，不機械替換所有「你」。

預留題號：日常 q31–127；吃喝 q128–224；旅行 q225–321；數碼 q322–418；相處 q419–515；取捨 q516–612；挑戰 q613–709；休閒 q710–806；品味 q807–903；腦洞 q904–1000。每類另有三題來自原有題庫。
