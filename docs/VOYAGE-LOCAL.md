# 最後一道燈光：12 幕冒險本機試玩

入口：`http://127.0.0.1/hoho-events/dist/story.html?demo=1&role=host`。
這次只完成本機原型，沒有推送 GitHub、沒有發布正式站或更改 Firebase 規則。無 demo 參數仍載入原有正式 18 幕故事。

## 立即試玩

1. 主持頁建立房間，新增暱稱或按「加入四位示範玩家」。點名字開玩家分頁，再開「文字直播展示」。
2. 每幕輪流指定一位主角，未當過主角的人優先，同次數按座位。主角只填自己的答案；其他人一起提交「猜主角的答案＋自己的答案」。截止前可修改。
3. 主持按「提前截止」→「揭曉首次選擇」。直播以真實玩家名字描述選擇，例如「小美選了一把珊瑚紅的工具。」並顯示每人猜對或猜錯。猜中加 1 分；主角漏答時不判定、不計分。
4. 默契只比較自己的初選與主角初選，不比較猜測。即使猜錯，自己的答案相同仍可增加默契。共同至少 2 次且相同率至少 70% 才靠攏；小群中每一對都須符合條件。作答中位置不變，揭曉後約 3 秒移動。
5. 按「帶出小變化」。大家可維持、改選或表示還需確認，自願填 100 字內短答。這次討論不另計猜測分數及默契。
6. 截止並按「揭曉變化，開始聊聊」。短答公開預設不勾，只有同意的句子展示；玩家可撤回，主持可隱藏。
7. 第三、七幕由當幕主角選路，所有人回答同一道情境，避免不同題目比較。第五幕最後選進觀測室者被困一幕，第六幕結束歸隊；題目仍以主角共同情境為準。
8. 第十二幕產生個人選擇回顧卡，可自願分享。私人短答不因分享卡片而公開。

可選「不限時」慢慢試玩。示範填答只填未提交者，短答加註「【示範短答】」。目前四位示範玩家停在第二幕揭曉，可看到「猜錯但自己的選擇相同」及兩角色靠近的效果。

第十一幕依最後明確選項的多數決定共同結局，並列依 A–D 固定順序，零票採安靜迎接。選「還要看」屬未決定，不計入最終多數。不另做競速或判定短答人格。

## 保存與原型限制

- 新存檔鍵 `hoho-voyage-local-v3`；重設會保留一份 `-backup`。舊 18 幕本機模式可用 `?demo=legacy`，其存檔獨立。
- 使用 Web Locks 和 storage event 同步同一來源、同一瀏覽器的分頁；重整恢復已提交答案及本場進度。未提交草稿在同階段其他玩家更新時保留，但重整不保證保留未提交內容。
- 這不是跨裝置多人版；同瀏覽器存檔可被讀取，不提供 Firebase 權限隔離。短答公開控制是本機展示行為，不能當正式保密邊界。
- 所有選項均為文字，包括五色小刀、提燈和紀念品，不生成選項圖片。顏色不推論人格。保留原有角色圖片。
- 非視覺題保留情境傾向次數供主持查看；短答不做 AI 分析，結局卡只記錄本人的實際選擇與句子。
- 原有正式多人遊戲與規則未修改，新版正式接入需另做 Firebase 資料結構及規則測試。
