# 來吧！我們互相傷害！

## 視覺方向
海邊小村莊裡，十隻假裝生氣的毛絨動物圍桌玩牌。直接採用使用者提供的原圖與角色，不以其他插畫取代；木牌 Logo 為最主要識別。

色彩：海水藍 #167c95、葉綠 #357153、沙白 #fff8e8、木棕 #78472b、珊瑚 #df694b、墨棕 #382c21。
字體：Noto Sans TC / Microsoft JhengHei；粗體標題呼應玩具牌，操作文字保持清晰。
版面：桌面以左側海島主圖、右側入場表單排列；手機先顯示木牌識別與表單。入場後讓題目與作答優先，背景退到周邊。

檢查：不加入與海島無關的紫色科技光效或戰鬥血條；使用原圖確保角色、材質和場景一致。主持工具保留高對比與文字標示。

## 玩法：嘴上互傷，桌上同樂
1. 選邊站：45 秒內選自己的答案，再預測最多人選的答案，一起提交；不比手速。
2. 猜大家：揭曉票數，猜中最多票選項得 1 分。最高票並列，猜任一並列選項都得分；零票不計分。
3. 聽故事：揭曉後分享原因，主持人先看投稿，再選到直播；可只玩不發言。

以房間累積分數呈現「猜大家排行榜」，原有計分與主持流程不變。「互相傷害」是輕鬆吐槽的主題，不新增淘汰、扣血、指定攻擊或人格判定。另有主持人專用的兩人默契，不與公開預測分數混合。

## 角色分派
十個角色都來自使用者提供的角色表。匿名登入產生隨機身分，以身分與房間碼映射至角色；不同人可相同，本場重整或重連保持一致。新房間重新分派，也可能得到同一角色。清除瀏覽器資料或更換瀏覽器會成為另一個身分。
角色純粹是外觀，不影響答案或分數；重複角色以暱稱、P01–P20 與「你」區分。十個角色已分別去背為透明 PNG，保留原始角色表。沒有換角色按鈕。

## 手機作答與散步

入場後以作答／聊天／排行榜切換，切換保留答案、聊天及故事草稿。題目、四個縱向選項、A–D 預測與提交優先；聊天入口有未讀提示，故事放在聊天分頁。頂部顯示已入座，不宣稱即時在線。

角色區水平捲動，「找到我」定位自己；揭曉後用 3 秒移到公開位置，平時小幅散步。共同回答至少兩題、相同率至少 70% 才靠攏；群內每一對都需合格，位置不是百分比尺。尊重系統減少動態，也提供手動選項；離開可見範圍與分頁隱藏會暫停。

新背景是獨立無角色海島插畫，所有題目、文字與按鈕都是網頁元素。OBS 保留原版面，不加入散步區。本版新增私人默契及公開位置資料，需要先發布更新後規則。

## 主持與直播展示頁改版（2026-10-14）

沿用海島主題：海水綠 #278b79、深葉綠 #23483f、木棕 #ae8550、奶白 #fffdf3、沙金 #f1d496。繁中 Noto Sans TC 保留；房間碼和題目使用粗體，說明文字收小。主持頁資訊左對齊，直播題目留寬行距。

主持頁採「房間資訊 | 本輪控制」雙欄，頂部兩位原角色作識別；手機改為上下排列。房間碼直接可見，連結緊接其下。已提交人數與階段提示放在控制區，結束／清理／登出收在原生可鍵盤展開的管理區。聊天、成員、投稿與私人默契維持獨立區域。

展示頁是海島舞台：上方房間狀態，中間題目及四張答案牌，右側排行榜，下方只放選中的故事。票數長條以實際票數占比呈現，最高票另有框線與星號，保留數字避免只靠顏色。沒有新增散步區或私人資料監聽。1080p 與 720p 依高度調整版面；一般小螢幕允許自然捲動。

驗收時縮短主持控制區，讓題目更早進入視野；修正展示網格最小高度造成的溢出，以及 720p 結果說明被截斷的問題。

## 玩家頁減量與全螢幕提示

沿用海島素材與奶白 #fffdf4、海綠 #078d7b、粉 #fce9ef、黃 #fff3c7、藍 #dfedff；圓厚黑體配立體陰影只用於短暫轉場。玩家頁以左對齊問題和大選項為主，接續散步區。房間／角色識別縮成一列，移除入房後品牌、重複聊天入口、提交成功通知、散步說明和手動減少動態勾選。系統 prefers-reduced-motion 仍有效。

聊天及交卷在固定畫面層飄過，與捲動位置無關；層不攔截點擊。揭曉等階段變化用滿寬木黃橫幅，2.8 秒後隱藏；重新整理不重播舊轉場。個人彈幕開關移到聊天分頁。揭曉後選項下顯示角色與暱稱，自己額外標示「你」，名單可換行。

## 頭像堆疊／名單彈窗原型

本機開啟 `http://127.0.0.1/hoho-events/prototypes/votes.html`，可切換多人分布、20 人同選、只有 1 人。這是獨立模擬資料，不讀寫 Firebase。玩家揭曉選項使用最多三個圓形角色及 +N，查看按鈕開啟原生 dialog 完整名單，保留座位與本人標示；零票不提供空的查看按鈕。設計經使用者確認後已整合至正式玩家頁。

已驗證 12／20 人名單、單人與零票、360px 無橫向溢出、Esc 關閉與焦點返回。共用 UI 已接入本機玩家頁，原有主持及 OBS 票數呈現不變，沒有調整資料或權限。
